## Bugs and feature requests

Open an issue on
[GitHub](https://github.com/emmaglorypraise/ObsidianLog/issues) — include
what you ran, what you expected, and what happened instead. For a bug,
`obsidianlog --version` and your OS/platform help a lot.

Found a security vulnerability? See
[Security Model](/architecture-and-security/security-model) — please report
those privately, not as a public issue.

## Questions and discussion

- **[Sia](https://sia.tech)'s community channels** — for anything about the
  underlying Sia network, `indexd`, or storage/wallet questions not specific
  to ObsidianLog itself.
- **The Vector community** — for questions about shipping logs into
  ObsidianLog via [Vector](https://vector.dev).
